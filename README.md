# Study here – study rooms with video (Socket.IO + WebRTC)

Sign up / sign in, join study rooms with shared focus timers, video + audio, screen share, chat, posts, follows and DMs.

## How it works
- **Socket.IO** (Node server) is the signaling channel: it relays WebRTC offers, answers and ICE candidates, and chat.
- **WebRTC** carries the video and audio directly between browsers (mesh, best for small rooms).
- **Auth:** email + password. Passwords are hashed with bcrypt, sessions are JWTs, and the Socket.IO connection is rejected without a valid token.
- **Storage:** SQLite file for accounts and content. If `DATABASE_URL` (Postgres, e.g. Neon) is set, a snapshot of the SQLite file is restored from Postgres at startup and saved back after every change, so data survives Render restarts.

## Run it on your computer
```bash
npm install
cp env.example .env      # set JWT_SECRET to a long random string
node --env-file=.env server.js
```
Open http://localhost:3000, create an account (the first account becomes admin). Camera access works on `localhost` without HTTPS. To test with two people on one machine, use two different browsers.

## Deploy on Render
1. render.com → New → **Blueprint** → connect this repo. It reads `render.yaml` and generates `JWT_SECRET` for you.
2. Set the env vars marked `sync: false` in `render.yaml` (see below).
3. Your app is at `https://<service-name>.onrender.com`. HTTPS is included, which browsers require for camera access.

### Environment variables
| Variable | Purpose |
|---|---|
| `JWT_SECRET` | Signs login tokens (auto-generated by `render.yaml`) |
| `DATABASE_URL` | Postgres connection string for permanent storage |
| `ADMIN_EMAIL` | Account with this email becomes admin on signup |
| `APP_URL` | Public URL, used in password-reset links |
| `BREVO_API_KEY`, `MAIL_FROM` | Send password-reset emails via Brevo |
| `METERED_API_KEY`, `METERED_DOMAIN` | TURN relay via Metered (recommended) |
| `TURN_URL`, `TURN_USERNAME`, `TURN_CREDENTIAL` | Alternative: your own TURN server |
| `FRAME_ANCESTORS` | Optional: sites allowed to embed the app |

### Free-tier limits to know
- The free service sleeps after inactivity, so the first visit can take up to a minute.
- Without `DATABASE_URL`, the SQLite file is wiped on restart or redeploy and accounts disappear.
- Meetings in progress end if the server restarts.

## When people can't connect
Some office and mobile networks block direct WebRTC. Add a TURN relay (Metered.ca has a free tier) by setting the Metered or TURN variables above. The app picks them up automatically, and `/healthz` reports whether TURN is active.
